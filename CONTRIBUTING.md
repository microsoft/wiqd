# Contributing to wiqd

Thank you for your interest in contributing to wiqd — the developer CLI for the M365 Copilot declarative-agent lifecycle.

## Reporting Issues and Requesting Features

- **In-product feedback** — run `wiqd feedback submit` to send structured bug reports, feature requests, and general feedback directly from the CLI. This is the primary channel for users of the published `@microsoft/wiqd` package and routes to the wiqd engineering team automatically.
- **Security vulnerabilities** — do **not** file a public issue. Report security vulnerabilities to the Microsoft Security Response Center (MSRC) per the instructions in [`SECURITY.md`](./SECURITY.md).
- **Source-access contributors** — if you have access to the wiqd source repository, you may also open an issue or pull request directly there. The source repository is currently private to Microsoft contributors; external contributors should use `wiqd feedback submit`.
