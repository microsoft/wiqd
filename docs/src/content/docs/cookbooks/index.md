# Cookbooks

wiqd cookbooks are short, end-to-end recipes built around one clear outcome. Follow them to create an agent, make it useful, validate it, improve its quality, and connect it to organizational knowledge.

Recipes range from creating your first agent to building specialized agents with tools such as MCP servers.
