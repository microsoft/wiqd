## Quick Start

```powershell
# One-liner install
iex "& { $(irm 'https://aka.ms/wiqd/install.ps1') }"

# Create and deploy an agent
wiqd agent create --name my-agent
wiqd agent validate --path my-agent
wiqd agent provision --path my-agent
```
