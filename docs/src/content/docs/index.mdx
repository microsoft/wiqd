## One plugin. The whole lifecycle.

**WIQD (Work IQ Dev Tools) is the agentic experience for building Microsoft 365 Copilot plugins
end to end.** Describe what you want to build, compose the capabilities you need, and let WIQD
guide you from an idea to a validated, provisioned, packaged, and shared or published plugin.
Use the same CLI commands directly when you need scripts or CI.

A **plugin** is the app package you ship. **Skills**, **connectors**, and **declarative agents**
are components you can compose into it; a declarative agent adds a conversational experience,
but a plugin does not need an agent to be useful.

The WIQD marketplace plugin installed in your coding assistant guides this work. It is a
different artifact from the Microsoft 365 plugin you are building.

## Quick Start

```powershell
# One-liner install
iex "& { $(irm 'https://aka.ms/wiqd/install.ps1') }"

# Create a plugin and compose its capabilities
wiqd plugin create --name my-plugin
cd my-plugin
wiqd plugin add skill --name "Triage Issues"
wiqd plugin add agent

# Validate, provision, and package
wiqd plugin validate --env dev
wiqd auth login --interactive
wiqd plugin provision --env dev
wiqd plugin package --env dev
wiqd plugin validate --mode deep --env dev
```

For guided authoring, install the [WIQD marketplace plugin](/getting-started/installation/#path-1-install-from-the-marketplace),
start a new session, and ask: **"Create a plugin with an issue-triage skill and a declarative agent."**
Follow the [Quickstart](/getting-started/quickstart/) for authentication and sharing, or
[Build a Plugin](/getting-started/build-a-plugin/) for connectors, publishing, and interoperability.

:::caution[Preview]
The `wiqd plugin` commands are alpha and enabled by default. Static validation checks the
declarative-agent surface; use package-first deep validation for the full app package.
Tenant catalog submission requires administrator approval before discovery.
:::
