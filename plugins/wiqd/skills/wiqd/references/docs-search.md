# Documentation Search

wiqd documentation is published at https://aka.ms/wiqd/docs — the site provides built-in full-text search — and also lives in-repo under `docs/src/content/docs/`.

To answer a documentation question:

- **Online:** point the user at https://aka.ms/wiqd/docs and use the site's search.
- **Local:** search `docs/src/content/docs/` directly with the `glob`/`grep`/`view` tools. Section subdirectories: `cli`, `getting-started`, `concepts`, `extensions`, `specs`, `project`, `pilot`.
